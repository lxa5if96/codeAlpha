# CodeAlpha Python Projects

This repository contains beginner-friendly Python projects created during my learning journey.

---

## Projects Included

### 1. Hangman Game
A simple word guessing game where users try to guess the hidden word letter by letter.

#### Features
- Random word guessing
- User input handling
- Win/Lose conditions

---

### 2. Stock Portfolio Tracker
A Python-based stock tracker that allows users to buy stocks, view investments, and save portfolio data.

#### Features
- View stock prices
- Buy stocks
- Track total investment
- Save portfolio into file

---

### 3. Simple ChatBot
A rule-based chatbot that responds to predefined user questions.

#### Features
- Greetings and conversations
- Joke responses
- Basic chatbot interaction
- Exit command
