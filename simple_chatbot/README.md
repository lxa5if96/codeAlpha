# Simple Python ChatBot

A beginner-friendly chatbot made using Python.  
This chatbot can answer predefined questions and interact with users in the terminal.

---

## Features

- Greeting responses
- Answers simple questions
- Tells jokes
- Friendly conversation
- Exit command

---

## Technologies Used

- Python

---

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/lxaa5if96/simple_chatbot.git
```

### 2. Open the project folder

```bash
cd simple_chatbot
```

### 3. Run the chatbot

```bash
python main.py
```

---

## Example Conversation

```text
You: hi
Bot: Hello!, How can i help you?

You: what is your name
Bot: My name is ASIF'S BOT.

You: tell me a joke
Bot: Why do programmers prefer Python? Because it's easy!

You: bye
Bot: Goodbye!
```
